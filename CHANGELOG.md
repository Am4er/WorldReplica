# Changelog

## Unreleased

- `/wr load` also finds schematics in WorldEdit's and FAWE's schematics folders

## 1.0.0

- Selection wand with two positions, given by `/wr select`
- `/wr save` and `/wr load` for Sponge `.schem` files, compatible with WorldEdit
- Saves and pastes run in the background and handle up to about two billion blocks
- `/wr cancel` and `/wr reload`
- Permission nodes for every command
- Optional Discord message when a schematic is saved
